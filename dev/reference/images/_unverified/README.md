# Unverified — held OUT of the register on purpose

Nothing in this directory is referenced by any `meta/*.json`, so nothing
downstream can treat it as evidence. Files land here when their **origin cannot
be established**, and they leave only when it can.

This exists because of A13 → A17. An invented ground-floor form survived two
review passes and reached half the buildings we generated, because a picture in
someone's head got filed where observations go. A17.4 and A18.3 answer that for
*prose*; this directory answers it for *pictures*.

## `haussmann-frontage_provenance-unknown.jpg`

A square-on frontage of a Haussmann-type *immeuble*: rusticated base, carriage
arch with an iron grille in its head, four étages with individual garde-corps,
mansard with segmental lucarnes.

**If it is a photograph it is one of the most useful images in the whole
register** — square-on, whole facade legible, and it shows garde-corps crossing
the lower part of each light exactly as A21 concluded.

**It is held back because I could not establish that it is one.**

- **No camera EXIF whatsoever** — no make, model, lens, exposure or capture
  date. Consistent with a stripped web repost; also consistent with generation.
- 864 × 1184, 72 dpi, progressive JPEG. No source URL was recorded.
- The facade is *unusually* regular: no weathering, no staining, no signage, no
  aerials, no people, no parked cars, and the neighbouring building at the left
  edge is oddly featureless.

None of that is proof either way, which is the point. Using it as corroboration
for A21 would be **circular** — the model already predicts what it shows, so if
it were generated it would prove nothing except that a generator agrees with us.

**To move it into the register**, one of: a source URL, an EXIF-bearing original,
a photographer, or an address that can be checked on a map.
